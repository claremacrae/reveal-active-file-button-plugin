# Contribution Guidelines

Thank you for your interest in contributing to this plugin.

This plugin is considered feature-complete, so changes are accepted only in limited circumstances. Before opening a pull request, please make sure that:

1. There is an existing GitHub issue describing the problem the change is intended to solve.
2. The maintainer has agreed in that issue that the proposed change would be useful.
3. The contribution was written by a human and was not generated by AI tools.

Pull requests that do not meet these criteria will be closed without review.

This policy helps keep the plugin small, stable, and maintainable. Thank you for understanding.
